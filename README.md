# 华为基站MML任务结果智能解析与转换工具

本工具专用于解析华为基站网管输出的MML任务结果TXT文件，将其高效转换为结构化的 **CSV** 或 **Excel (.xlsx)** 文件。

针对实际场景中**千万行级数据**，本工具采用了**双遍流式状态机引擎（Two-Pass Streaming State-Machine）**，内存占用极低（稳定在几十MB以内），解析吞吐量高。

---

## 核心特性

1. **自动展开复合开关（分类集与子类）**：
   - 将例如：
     ```text
     语音策略开关  =  EPS FB开关:开
                   =  VoNR/EPS FB自适应开关:开
                   =  EPS FB最强邻区重定向开关:开
     系统间业务移动性算法开关  =  移动至E-UTRAN开关:开
                               =  NSA与SA优选RSRP预测开关:关
     ```
     自动转化为独立列名：
     `语音策略开关&EPS FB开关`、`语音策略开关&VoNR/EPS FB自适应开关`、`系统间业务移动性算法开关&移动至E-UTRAN开关` 等，值填充为 `开`、`关`。
   - 无论是键值对格式（` = `）还是表格单元格（`&` 分隔的复合文本），均能完美对齐与展开。
   - 对非复合参数（如 `时隙配比 = 单周期8:2时隙配比`）自动保持原样，不会被错误切割。

2. **自动标记元数据来源**：
   - 每一行数据开头均标明：
     - **`文件来源`**：源TXT文件名（如 `MML任务结果_201111_20261111_144007.txt`）。
     - **`网元名称`**：所属基站网元（如 `郑州惠济国基大学城公寓微站-微-H-共主控`）。
     - **`执行时间`**：从报文时间戳中提取的标准时间（如 `2026-11-11 14:39:51`）。
     - **`MML命令`**：执行的具体命令（如 `LST NRCELLALGOSWITCH:`）。

3. **千万行级大数据高性能架构**：
   - **零内存堆积**：采用 Python 生成器流式逐行解析，边解析边缓冲写入磁盘，即使处理 50GB 大文件也不会发生内存溢出（OOM）。
   - **智能编码适配**：毫秒级自动探测 `GB18030`、`GBK`、`UTF-8`、`UTF-8 BOM`，防止中文出现乱码。
   - **Excel防乱码**：导出的 CSV 文件默认采用带 BOM 的 `utf-8-sig` 编码，双击即可在微软 Excel 中正常打开。

4. **多命令分表与合并输出**：
   - 不同 MML 命令（如 `LST NRDUCELL` 与 `LST NRCELLALGOSWITCH`）的参数架构完全不同。
   - 工具会自动将相同命令的数据合并归类到对应的 CSV（如 `LST_NRDUCELL.csv`）或 Excel 中的各个独立工作表（Sheet）。

## 使用方法

### 方式一：桌面图形界面（推荐）

1. **双击启动**：
   直接双击运行目录下的 **`运行MML解析转换工具.bat`**。
2. **选择文件**：
   - 点击 **“📁 添加TXT文件”**（支持按住 Ctrl / Shift 多选）。
   - 或点击 **“📂 添加文件夹”** 自动递归扫描整个目录下的全部 TXT 文件。
3. **选择导出格式**：
   - **CSV 格式**（默认推荐）：速度最快，支持千万行海量数据，无行数限制。
   - **Excel 格式**：按命令生成多 Sheet 的 `.xlsx` 文件（注意：单个 Excel 工作表最大支持 1,048,576 行）。
   - **CSV + Excel**：两者均导出。
4. **点击“🚀 开始解析并导出”**：
   界面实时显示解析进度、当前处理文件和已解析行数。完成后点击 **“📂 打开输出文件夹”** 即可查看结果。

---

### 方式二：命令行调用（自动化脚本/后台调度）

通过终端直接执行 `mml_parser.py`：

```bash
# 1. 解析单个或多个文件，导出为CSV（默认）
python mml_parser.py "F:\mml\MML任务结果_201111_20261111_144007.txt" -o "F:\mml\output"

# 2. 批量解析整个文件夹中的所有TXT文件
python mml_parser.py "F:\mml" -o "F:\mml\output" -f csv

# 3. 导出为 Excel 格式 (.xlsx)
python mml_parser.py "F:\mml" -o "F:\mml\output" -f excel

# 4. 同时导出 CSV 和 Excel
python mml_parser.py "F:\mml" -o "F:\mml\output" -f both
```

参数说明：
- `input`：待处理的单个 TXT 文件、多个 TXT 文件或文件夹路径。
- `-o, --output`：导出结果的存放目录，默认为 `./output`。
- `-f, --format`：输出格式，可选 `csv`、`excel` 或 `both`。
